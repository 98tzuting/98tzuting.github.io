AFM（Atomic Force Microscopy）簡介

AFM（Atomic Force Microscopy，原子力顯微術）是一種以掃描探針為基礎的奈米尺度分析技術。 與利用光線或電子束形成影像的顯微鏡不同，AFM是利用非常尖銳的探針在樣品表面進行掃描， 並偵測探針與樣品之間產生的微小作用力，藉此取得樣品的表面資訊。 因此，AFM不僅能觀察奈米尺度的表面形貌，也能進一步量測材料的機械、電性、磁性及其他局部性質。

AFM的一項重要特色是不要求樣品具有導電性，因此金屬、半導體、絕緣材料、 薄膜、高分子與部分生物材料皆可進行分析。 透過不同的探針與量測模式，可以依照樣品特性與研究目的選擇適合的分析方式。

AFM的基本組成

一套典型的AFM主要由探針（Tip）、懸臂（Cantilever）、雷射與光電偵測系統、 掃描器（Scanner）、樣品平台及回授控制系統組成。 探針通常製作在懸臂前端，探針尖端的曲率半徑會直接影響橫向解析能力。 當探針受到樣品表面的作用力時，懸臂會產生極微小的彎曲或振動變化。

AFM常使用光學槓桿（Optical Lever）方式偵測懸臂的變化。 雷射光會照射在懸臂背面，再反射至光電偵測器。 當懸臂發生偏轉時，反射雷射的位置也會隨之改變， 儀器便能將這個微小的位置變化轉換成可分析的訊號。

在掃描過程中，系統會利用回授控制器調整Z方向的位置， 使探針與樣品之間維持適當的交互作用。 同時記錄X、Y方向的掃描位置以及Z方向的高度變化， 最後將大量量測點組合成樣品表面的三維形貌影像。

AFM成像原理

AFM的基本概念可以理解為「利用探針感受表面起伏」。 當探針沿著樣品表面逐行掃描時，表面的高低變化會改變探針與樣品之間的作用力， 造成懸臂產生偏轉或振幅變化。 控制系統根據偵測到的訊號即時調整探針高度，使探針能夠追蹤樣品表面的輪廓。

探針與樣品之間可能存在多種作用力，例如凡得瓦力、靜電力、 毛細作用力以及接觸產生的排斥力等。 實際量測時所偵測到的訊號會受到探針、樣品表面、環境及操作模式影響。 因此AFM影像並不是單純的「放大照片」，而是由探針與樣品交互作用所得到的量測結果。

AFM常見量測模式

量測模式 探針狀態 主要特徵 常見用途
Contact Mode 持續接觸樣品表面 以懸臂偏轉與回授訊號追蹤表面高度 表面形貌、粗糙度及需要直接接觸的量測
Tapping Mode 探針振盪並間歇接觸表面 降低掃描時的橫向作用力 薄膜、高分子、微奈米結構及較脆弱樣品
Non-Contact Mode 探針保持在樣品表面上方 利用非接觸狀態下的作用力進行量測 降低探針與樣品直接接觸造成的影響

在Tapping Mode中，懸臂會接近其共振頻率進行振盪， 探針與樣品表面的間歇性接觸會造成振幅改變。 系統透過維持設定的振幅並調整Z方向位置來追蹤表面高度。 相較於持續接觸的方式，Tapping Mode可降低掃描時的側向作用力， 因此常用於較容易受到機械作用影響的樣品。

AFM影像可以觀察什麼？

AFM最基本的輸出結果是樣品表面的Topography（表面形貌）。 透過三維形貌資料，可以分析表面顆粒、孔洞、薄膜結構、台階與局部缺陷等特徵。 除了直接觀察影像，也可以利用高度資料進行定量分析。

分析項目 說明
Surface Roughness 評估樣品表面的粗糙程度
Height 量測表面結構、顆粒或台階的高度差
Width / Size 分析表面結構的尺寸與間距
Line Profile 沿指定路徑分析表面的高度變化
3D Topography 利用高度資料建立樣品表面的三維視覺化結果

AFM的延伸分析

AFM並不只侷限於表面形貌量測。 透過不同的探針、訊號與操作模式，可以將AFM延伸至材料性質分析。 例如電性相關模式可分析表面電位與局部電流， 磁性相關模式可以研究磁性結構， 而力學相關量測則能分析探針與材料接觸過程中的作用力及材料的機械性質。

NIST資料指出，現代AFM已經從單純的表面形貌觀察， 發展至機械、電性、磁性及化學等不同性質的奈米尺度分析。 在奈米機械量測中，也可以進一步取得彈性模數、黏附力、 摩擦及黏彈性等材料資訊。

AFM的應用

AFM可應用於材料科學、半導體、奈米科技、生物材料及表面工程等領域。 在半導體與微奈米製程中，可利用AFM分析表面粗糙度、 結構尺寸、線寬、深度與表面缺陷。 對薄膜與材料研究而言，AFM也能用於比較不同製程條件所造成的表面形貌差異。

由於AFM能夠在奈米尺度進行局部量測， 因此也適合用於研究單一顆粒、奈米結構、薄膜表面以及材料界面。 搭配不同AFM模式後，還可以將表面形貌與材料其他性質進行關聯分析。

AFM量測時的注意事項

AFM的量測結果會受到探針狀態、樣品固定方式、掃描速度、 回授設定及環境振動等因素影響。 探針尖端若受到碰撞或磨損，可能造成影像解析度下降， 或產生與真實樣品形貌不同的影像特徵。

掃描速度與回授參數也需要配合樣品表面起伏進行調整。 若回授速度不足，探針可能無法正確追蹤表面高度， 造成影像中的結構失真或Trace與Retrace差異。 因此實際量測時，應先取得穩定且可重現的影像，再進行後續定量分析。

AFM量測流程

選擇適合的AFM探針
安裝探針並確認懸臂狀態
固定樣品
調整雷射位置與光電偵測器訊號
選擇適合的AFM量測模式
設定掃描範圍與影像解析度
進行探針Approach
調整回授及掃描參數
