PEC（Proximity Effect Correction）簡介

PEC（Proximity Effect Correction，鄰近效應修正）是電子束微影 （Electron Beam Lithography, EBL）中非常重要的製程技術。 電子束在光阻上進行曝光時，入射電子並不會只沿著原本的直線路徑前進， 而會與光阻及基板中的原子產生散射，使電子能量分布到原始曝光位置以外的區域。

當相鄰圖形距離較近時，一個圖形所產生的散射電子會對周圍圖形造成額外曝光， 使不同位置實際受到的曝光劑量與設計值產生差異。 這種由鄰近圖形造成的非預期曝光效應稱為Proximity Effect。 PEC的目的，就是利用劑量修正來補償這些額外的能量沉積， 使顯影後的圖形尺寸更接近原始設計。

核心概念： 電子束微影的Proximity Effect主要與電子散射造成的能量沉積範圍有關， 其中前向散射主要決定較小尺度的曝光擴散， 背向散射則會在較大的範圍內提供額外曝光。

Proximity Effect的形成原因

電子束進入光阻後，會在光阻與基板材料中發生不同程度的散射。 其中前向散射（Forward Scattering）主要發生在電子穿過光阻的過程， 使電子束在光阻內逐漸展開。 另一方面，部分電子會深入基板後受到大角度散射並重新返回光阻， 形成背向散射（Backscattering）。

因此，即使電子束本身具有非常小的聚焦直徑， 最終在光阻中實際產生的能量分布仍然會擴散到更大的區域。 對於密集排列的圖形而言，鄰近圖形所產生的散射電子會彼此疊加， 導致局部曝光劑量增加。

Forward Scattering（前向散射）

α Effect

前向散射主要發生於電子束穿過光阻層時。 電子受到光阻材料中的原子散射後，行進方向會產生偏移， 使原本集中的電子束在光阻深度方向逐漸展開。

前向散射的特徵尺度通常較小，因此對奈米尺度圖形的解析度與線寬 具有直接影響。光阻厚度與材料性質改變時，前向散射造成的展寬程度也會改變。

α：短距離散射尺度

在常見的Proximity Effect模型中， α可用來描述前向散射造成的局部曝光擴散尺度。 α越大，表示電子束在光阻內的橫向能量分布越寬， 可能造成較明顯的圖形展寬。

Backscattering（背向散射）

β Effect

部分入射電子會穿過光阻並進入基板， 在基板中受到較大角度的散射後重新返回光阻附近。 這些返回的電子會在原始曝光位置周圍額外產生能量沉積， 形成範圍較大的背景曝光。

因此，背向散射對較大範圍內的鄰近圖形具有影響， 特別是在密集圖形、大面積圖形或高劑量曝光條件下， 其效應可能更加明顯。

β：長距離散射尺度

在Proximity Effect模型中， β通常用來描述背向散射所造成的較大尺度曝光分布。 與α相比，β的作用範圍通常大得多， 因此會形成較廣泛的背景劑量。

α與β的差異

項目 前向散射 α 背向散射 β

主要位置 光阻層內 基板與光阻附近
散射範圍 較小 較大

Proximity Effect的劑量分布

PEC常使用雙高斯（Double Gaussian）模型近似電子束在光阻與基板中的能量分布。 其中較窄的Gaussian分布描述前向散射， 較寬的Gaussian分布則描述背向散射。

Point Spread Function（PSF）

PSF(r) = (1 - η) / (π α²) × exp(-r² / α²) + η / (π β²) × exp(-r² / β²)

其中α代表前向散射的特徵尺度， β代表背向散射的特徵尺度， η則代表散射電子所占的相對比例。 透過此類模型，可以描述單一電子束曝光後在空間中的能量沉積分布， 並進一步估算相鄰圖形對目前曝光位置所造成的額外劑量。

Proximity Effect的實際影響

假設兩個相鄰圖形分別需要相同的設計劑量， 但其中一個圖形附近具有較多的曝光面積， 則它所接收到的背向散射電子可能比孤立圖形更多。 因此，即使兩個圖形設定相同的Primary Dose， 最終的有效曝光劑量仍可能不同。

這種情況可能造成圖形尺寸偏差， 例如線寬變粗、間距縮小、孔洞尺寸改變或密集圖形與孤立圖形之間產生CD差異。 對高解析度電子束微影而言， 這種非均勻曝光會限制圖形轉移的準確度。

PEC的基本原理

原始Pattern → 散射模型 → 計算額外曝光劑量 → Local Dose Correction → Electron Beam Exposure → Develop → CD確認

PEC的主要概念是將整個圖形拆解成不同區域， 先根據每個位置周圍的圖形分布計算其預期受到的散射劑量， 再調整各區域的電子束曝光劑量。

當某一區域因鄰近圖形而接受較高的散射劑量時， PEC會降低該區域的Primary Exposure Dose； 相反地，對於受到鄰近散射影響較小的區域， 則可能需要較高的曝光劑量。 最終目標是讓整個圖形的Effective Dose更加均勻。

孤立圖形與密集圖形

Isolated Pattern

圖形周圍沒有大量鄰近曝光區域， 因此受到其他圖形所產生的背向散射影響較小。 其Effective Dose較接近原始設定的Primary Dose。

Dense Pattern

周圍存在較多曝光區域， 不同位置產生的背向散射會相互疊加， 因而使局部Effective Dose增加。

PEC與黃光製程的關係

在黃光製程環境中，電子束微影通常與一般光學微影使用不同的圖形曝光方式。 一般光學微影利用光罩與光線進行圖形轉移， 而電子束微影則利用聚焦電子束直接在光阻上進行寫入。

因為電子束寫入過程會受到前向散射與背向散射影響， 所以在進行EBL曝光前需要考慮Proximity Effect。 PEC便是在曝光前先計算不同圖形位置所需要的局部劑量， 使顯影後得到的圖形能夠更接近Design Layout。

PEC與OPC的區別

PEC與OPC雖然都與微影圖形的尺寸修正有關， 但其物理來源與使用方式不同。 本頁所討論的PEC主要針對電子束微影中的電子散射效應， 特別是前向散射α與背向散射β所造成的額外曝光劑量。

OPC（Optical Proximity Correction）則主要用於光學微影， 用來補償光學系統中的繞射、干涉及鄰近圖形造成的成像誤差。 因此兩者雖然都具有「修正微影圖形」的目的， 但不能將PEC與OPC視為完全相同的技術。

製程結果確認

PEC完成後仍需要透過實際電子束曝光與顯影確認修正效果。 常見的確認方式包括SEM觀察、CD量測以及不同Pattern Density之間的尺寸比較。 若實際CD仍與Target CD存在偏差， 可依量測結果重新調整散射模型或Local Dose參數。

因此完整的PEC並不是一次性的劑量設定， 而是建立「模型 → 劑量修正 → 曝光 → 顯影 → CD量測 → 模型調整」的迴圈， 逐步改善圖形轉移的準確度。

重點整理

  1. Forward Scattering（α）： 主要描述電子在光阻內的前向散射，影響較小尺度的曝光擴散。
  2. Backscattering（β）： 電子進入基板後受到散射並返回光阻附近，形成較大範圍的額外曝光。
  3. Proximity Effect： 鄰近圖形所產生的散射電子會改變局部Effective Dose。
  4. PEC： 根據散射模型及Pattern Density調整Local Exposure Dose， 以補償鄰近效應造成的尺寸偏差。
  5. OPC： 主要是光學微影中的鄰近效應修正方法，與EBL PEC的物理機制不同。
